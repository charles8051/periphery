// Blocking waits, banned in the browser packages. ADR-0092 D8 has the reasoning.
//
// A browser runs .NET on one thread. A blocking wait on a task that a JS promise completes waits
// for the event loop it is holding, so the page hangs. `await` is not affected: the analyzer reports
// explicit calls, and an await expression is not one.
M:System.Threading.Tasks.Task.Wait;Blocks the only thread, which hangs the page. Await the task instead. See ADR-0092 D8.
